> This file grows over time as I (Pat) hit issues installing the stack.

---

## Format

Each issue is logged with :

- **Date** : when it happened
- **Symptom** : what I saw / what broke
- **Diagnosis** : what was actually wrong
- **Fix** : exact command(s) or config change that resolved it
- **Notes** : anything else useful (browser version, Windows build, etc.)
